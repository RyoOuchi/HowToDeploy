# Video Creation Guide

Remotion × CodexでアプリPVを作る、日本語の静的ドキュメントです。
`LightningPage-release.zip` のレイアウト・スタイル・コピー機能をベースに、`video_creation.md` の内容をまとめています。

## 開き方

ZIPを展開し、`index.html` をブラウザで開いてください。インストールやビルドは不要です。
公開する場合は、このフォルダの内容をそのまま静的ホスティングへ配置できます。相対パスなのでサブディレクトリにも配置できます。

```text
index.html          日本語の5ステップガイド
style.css           レスポンシブ表示・印刷用スタイル
script.js           プロンプトのコピー・目次の現在位置・動画再生の制御
assets/
  videos/           ぼかし加工済みMP4 × 5
  posters/          加工済みMP4から抽出したJPEG × 5
  manifest.json     素材の由来・SHA-256・動画情報
```

## 動画について

動画はすべて `Assets/Redacted/` からそのままコピーした加工済みファイルです。元のMOVや未加工のMP4は含めていません。ポスター画像も加工済みMP4から作成しています。5本とも音声はありません。

- `remotion-tutorial.mp4` — ステップ1、日本語解説・キー表示付き
- `init-remotion.mp4` — ステップ1の補足、解説表示なしの初期設定録画
- `MoveCodebase.mp4` — ステップ2、コードのコピーと名前変更
- `AskChatGPT.mp4` — ステップ3、参考PVの検索
- `OpenCodex.mp4` — ステップ4、Codexのプロジェクト作成

## 使い方と編集

- コマンドやプロンプトは「コピー」ボタンで全文をコピーできます。ブラウザがコピーを許可しない場合は、本文を選択してコピーしてください。
- 動画は再生するまで読み込まれません。再生すると、ほかの動画を一時停止します。
- JavaScriptを無効にしても本文・目次・動画・折りたたみは利用できます。
- 外部フォント、CDN、解析ツール、外部JavaScriptへの依存はありません。
- 内容は `index.html`、見た目は `style.css`、動作は `script.js` で編集します。
- 原稿内のプロンプトは資料の例文として掲載しています。制作の実行や外部への公開は行っていません。

## 検証

- 390px・847px幅で表示を確認。横方向のはみ出しなし。
- ローカルHTTPプレビューで5本すべての再生、動画の同時再生防止、折りたたみ時の一時停止を確認。
- プロンプトのコピー操作と完了表示、目次リンクの動作を確認。
- 原稿と掲載プロンプトの全文一致、ローカル素材リンク、見出しID、ARIA参照、JavaScript構文を確認。
- 5本すべてのMP4について、加工済みの元ファイルとのSHA-256一致を確認。
